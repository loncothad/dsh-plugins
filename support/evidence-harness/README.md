# Evidence Harness

Connect DSH's public provider, session and profile APIs to Evidence Store. Provides original-log capture, protocol grouping, extraction, request manifests and standard/PTC compactor replacement.

Consumed by Evidence Compactor. Token counts include conservative estimates; credentials belong to the selected provider.

[API and implementation reference](https://github.com/loncothad/dsh-plugins/blob/main/docs/support/evidence-harness.md).
