# Media Generation

Shared media contracts, catalog controls, tools, skills and slash commands for fal and OpenRouter.

Validates model inputs and options, bounds requests and downloads, publishes files inside the admitted workspace and rolls back owned files after failure. Text-only results need no file publication.

[API and implementation reference](https://github.com/loncothad/dsh-plugins/blob/main/docs/support/media-gen.md).
