# OpenAI-compatible LLM Adapter

Adapt native DSH requests to OpenAI Chat Completions: streaming, tool calls, usage and coded errors.

Provider plugins supply the endpoint, credentials, catalog and headers. This is a dependency, not an activated plugin.

[API and implementation reference](https://github.com/loncothad/dsh-plugins/blob/main/docs/support/llm-openai-compat.md).
