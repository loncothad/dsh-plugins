# Plan & Goals

Use `/goal IDEA` for adaptive work or `/sisyphus IDEA` for an ordered plan. Answer a native clarification question, review tasks and completion checks in **Session tools > Plan & goals**, then confirm execution.

The chat card tracks tasks, blocking reasons, evidence and audit feedback. `/goal-tweak CHANGE` amends the same goal; `/goal-replace IDEA` reviews a fresh one. `/goal-pause` and `/goal-resume` control continuation.

Configure independent audits, completion rules and limits globally or per chat. Audits can run after each task or at the end. Accepted task completion triggers compaction by default; this is configurable.
