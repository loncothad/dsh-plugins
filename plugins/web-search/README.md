# Web Search

Configure Exa, Kagi, OpenRouter, OpenAI API or ChatGPT Codex search in Plugins. Providers have separate controls and model selectors.

Only Exa is enabled by default, using public MCP search when no key is set. Other API providers require both enablement and a key. Codex requires enablement and a signed-in account.

Codex uses the active account shown in ChatGPT Codex. OpenAI API uses a separate key and API billing; credentials never fall back between the two.
