# ChatGPT Codex

Use a ChatGPT Codex subscription as a DSH model provider. Sign in from Plugins with browser or device authorization; prefer device authorization for a remote host. Credentials stay on the host.

Manage accounts and select a model in DSH. Each account shows subscription type, remaining quota, renewal times and available resets. Reset actions require confirmation.

`/codex-accounts`, `/codex-use`, `/codex-status` and `/codex-logout` manage accounts. Configure speed, account fallback and image generation in Plugins. Local usage-counter reset does not renew subscription quota.
