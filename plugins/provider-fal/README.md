# fal Media

Generate images, video, audio and 3D assets, or run transcription and media understanding through fal's advertised models.

Set `FAL_KEY` or add a key in **Plugins > fal Media**. Choose task defaults using the searchable catalog with prices, capabilities and “Released on fal” dates. Newest models appear first; unavailable metadata stays unknown.

Use `/fal-models` to browse and `/fal-media @MODEL PROMPT` to run. Configure model options, task/tool/command/skill toggles and resource limits in Plugins. Generated files stay in the chat workspace.
