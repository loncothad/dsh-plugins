# System Prompt Replace

Replace DSH's system-prompt sections with one inline prompt or file. Configure the source, variable interpolation and runtime-context behavior in Plugins. `/system-prompt` shows the active replacement.

This removes native identity and guidance sections. Tools and variables still resolve. File changes require a plugin reload. A complete replacement overrides Agents Switch and other prompt sections.
