# Context Inspector

Inspect the last main-model request: its route, context capacity, messages, tools and compaction ranges. Open it from **Session tools** and configure preview limits in **Plugins > Context Inspector**.

Text previews are off by default. Token estimates are labeled as estimates. Private summaries, auxiliary requests and credentials are excluded. This is a human inspection panel with no model tool.
