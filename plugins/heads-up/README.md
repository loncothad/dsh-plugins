# Heads Up

Show private risk notices alongside chat. Open **Session tools > Heads Up** or run `/heads-up review`.

Local checks need no API. Optional independent model review is off by default, needs Execution Recovery and may incur charges. Configure review scope and limits in Plugins.

**Understood** or **Dismiss** keeps a notice private. **Discuss** explicitly shares it with the chat model. Notices do not grant permission or certify work.
