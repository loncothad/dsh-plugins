# Conversation Summaries

Show incremental summaries in private chat cards. Use `/summary now` or **Session tools > Summaries**; `/summary status` and `/summary cancel` inspect or stop a run.

Choose a local digest or a registered model in Plugins. Optional triggers run every N turns or use a decision model. Automatic delivery is off by default.

External summary text stays outside the main model's context and compaction. Model-backed runs need Execution Recovery and may incur provider charges.
