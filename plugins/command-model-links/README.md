# Model Links

Group equivalent `provider/model` routes in **Plugins > Model Links** and choose their order.

Use `/model-links` to inspect groups, `/model-link ROUTE=ROUTE` to join routes, `/model-unlink ROUTE` to remove one, and `/model-cycle` to switch. Use Fallback Router for automatic recovery after request failures.
