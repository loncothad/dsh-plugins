# OpenRouter

Use OpenRouter chat and media models. Set `OPENROUTER_API_KEY` or add a key in Plugins, then select models in DSH.

Filter the model list by price, context, catalog age and vendor. Choose upstream providers directly in the list; per-model preferences override global routing. Available prices, performance and retention evidence are shown, with unknown values labeled.

Use `/openrouter-models`, `/openrouter-provider` and `/openrouter-media`. Configure media defaults, options and limits in Plugins. Privacy preferences apply to chat and media; incompatible protocols fail before dispatch. Video generation is not ZDR eligible.
