# Path Globs

Expand file globs in user messages and preview matches with `/glob preview PATTERN` or **Session tools > Glob preview**. Snapshots contain file names, not file contents.

Configure project-root filtering in Plugins. Honoring ignores is optional; `.gitignore`, `.ignore` and extra ignore-file names are independently configurable. Explicit exclusions still apply when ignore files are disabled.

Fenced code is skipped. URLs, path traversal, symlinks and incomplete results caused by limits are rejected.
