# Policy Engine

Decide whether an action may run through explicit rules, evidence requirements and human approval. Configure **Off**, **Observe** or **Enforce** in Plugins; `/policy` shows status.

Approvals can cover one request or a scoped family of similar actions. Inspect, expire or revoke them in Session tools.

**Honor Full Access** is on by default: native Full Access bypasses unmatched default reviews. Explicit rules, evidence requirements and native guards still apply.
