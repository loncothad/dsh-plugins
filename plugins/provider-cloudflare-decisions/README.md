# Cloudflare Decisions

Use Clef or Clef Flash for typed choice, score and yes/no decisions, with optional image input.

Set a Cloudflare account ID and Workers AI token in Plugins, choose the default model, then select Cloudflare in Decision Models. Provider execution and vision have independent toggles.

Embedded PNG, JPEG and WebP images are supported; remote image URLs are rejected. Reported probabilities remain model output, not permission or proof.
