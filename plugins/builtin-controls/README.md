# Built-in Controls

Enable or disable native runtime plugins, preset components and skills from **Plugins > Built-in Controls**, or **Settings > Built-in plugins > Controls**.

Runtime changes use DSH's manager. Preset changes apply to new or resumed chats. Skill changes block future loading, including in open chats. Protected host components stay locked; disabling a skill does not remove instructions already in chat history.
